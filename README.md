# 🎮 Выживание со слизнями

Аркадная игра-выживалка на Python с использованием библиотеки Arcade.

## 📖 Описание

Выживайте 15 минут, уничтожая волны слизней и мини-боссов в бесконечно генерируемом мире с разными биомами. Прокачивайте персонажа, выбирая улучшения при повышении уровня.

### Особенности:

- 🌍 Бесконечный процедурно генерируемый мир
- 🎨 Разные биомы с уникальными эффектами
- 👹 Мини-боссы на 5-й и 10-й минуте
- ⬆️ Система улучшений при повышении уровня
- 🏃 Механика спринта с выносливостью
- 📈 Прогрессия сложности со временем

## 🚀 Запуск

### Требования

- Python 3.10+

### Установка

1. Клонируйте репозиторий:

```bash
git clone https://github.com/dregorianec/vetochka_dlya_velikogo.git
cd vetochka_dlya_velikogo
```

2. Создайте виртуальное окружение (опционально):

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
# или
source .venv/bin/activate  # Linux/Mac
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите игру:

```bash
python main.py
```

## 🎯 Управление

| Клавиша                | Действие                                                     |
| ----------------------------- | -------------------------------------------------------------------- |
| W/A/S/D или стрелки | Движение                                                     |
| ЛКМ                        | Выстрел                                                       |
| ПКМ (зажать)         | Авто-стрельба (при активном бонусе)     |
| Shift                         | Спринт (тратит выносливость)                 |
| Мышь                      | Выбор улучшений при повышении уровня |
| ESC                           | Выход (на экране победы)                          |

## 🏆 Цель игры

Продержитесь **15 минут**, убивая врагов и собирая опыт. На 5-й и 10-й минуте появляются мини-боссы!

## 📦 Структура проекта

```
├── main.py          # Основная логика игры
├── classes.py       # Классы персонажей, врагов, боссов
├── requirements.txt # Зависимости
├── pictures/        # Спрайты и текстуры
│   ├── anim/        # Анимации
│   └── photo/       # Статичные изображения
├── sound/           # Звуковые эффекты
└── текстуры/        # Тайлы карты
```

## 🎮 Улучшения

При повышении уровня выбирайте из 3 случайных улучшений:

- Скорость +5%
- Боезапас +2
- Тройной выстрел
- Двойной выстрел
- Быстрая перезарядка
- Выносливость
- Скорость пули
- Дальность стрельбы
- Пробитие
- И другие...

## 👹 Боссы

### Страж Орбит (5 минута)

- Красный босс с вращающимися огненными орбитами
- Ломает стены на пути

### Астральный Стрелок (10 минута)

- Синий босс, стреляющий снарядами
- Телепортируется каждые 8 секунд
